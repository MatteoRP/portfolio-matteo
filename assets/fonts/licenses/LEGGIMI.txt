Font di questo sito: licenze e provenienza
==========================================

Il sito usa solo due famiglie, tutte in locale (self-hosted): niente collegamenti a servizi esterni.
Sono nel sottoinsieme "latin", un file .woff2 per ogni peso, e si caricano con font-display: swap.

Font              Uso                                         Pesi           Licenza   Licenza (file)            Repository ufficiale
----------------  ------------------------------------------  -------------  --------  ------------------------  ----------------------------------------------
Inter             titoli (700), testo e pulsanti (400, 500)   400, 500, 700  OFL 1.1   OFL-inter.txt             https://github.com/rsms/inter
Instrument Serif  parole chiave, lead e numeri grandi         400 corsivo    OFL 1.1   OFL-instrument-serif.txt  https://github.com/Instrument/instrument-serif

Provenienza dei file
- Inter: file OTF di Inter 4.0, ridotti al sottoinsieme latin e convertiti in .woff2 con pyftsubset (fonttools).
- Instrument Serif: pacchetto npm @fontsource/instrument-serif (versione 5.x), file latin 400 corsivo.

Cosa NON c'è più: Inter Tight, Geist Mono, Rock Salt e il tondo di Instrument Serif non sono più usati e i loro file sono stati tolti.

Le licenze permettono di ospitare i file sul proprio sito. L'OFL non permette di vendere i font da soli:
qui non vengono venduti, sono parte del sito.
