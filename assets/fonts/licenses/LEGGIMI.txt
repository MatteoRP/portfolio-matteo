Font di questo sito: licenze e provenienza
==========================================

Tutti i font sono usati in locale (self-hosted), solo nel sottoinsieme "latin", un file .woff2 per ogni peso.
I file sono presi dai pacchetti npm @fontsource (versione 5.3.0) e confrontati con le licenze nei repository ufficiali.

Font              Uso                               Licenza     Licenza (file)                  Repository ufficiale
----------------  --------------------------------  ----------  ------------------------------  --------------------------------------------
Inter Tight       titoli (600, 700, 800)            OFL 1.1     OFL-inter-tight.txt             https://github.com/rsms/inter-tight
Inter             testo (400, 500)                  OFL 1.1     OFL-inter.txt                   https://github.com/rsms/inter
Instrument Serif  parole chiave (400, 400 corsivo)  OFL 1.1     OFL-instrument-serif.txt        https://github.com/Instrument/instrument-serif
Geist Mono        etichette (400, 500)              OFL 1.1     OFL-geist-mono.txt              https://github.com/vercel/geist-font
Rock Salt         annotazioni a gesso (400)         Apache 2.0  Apache-2.0-rock-salt.txt        https://github.com/google/fonts/tree/main/apache/rocksalt

Rock Salt: copyright 2010 Font Diner, Inc DBA Sideshow. Le annotazioni a gesso arrivano in un passo successivo:
per ora il font è dichiarato nel CSS ma non viene scaricato dal browser, perché nessun elemento lo usa.

Tutte queste licenze permettono di ospitare i file sul proprio sito. L'OFL non permette di vendere i font da soli:
qui non vengono venduti, sono parte del sito.
